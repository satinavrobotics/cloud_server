# VDA5050 open items (2026-10-09)

## 1. Confirmed decisions

- **Last-node tolerance:** the robot counts its final position reached at 0.35-0.45 m and cannot honour a tighter `allowedDeviationXY` yet. The server sends 0.35 m for the last node (`ROUTE_DEVIATION_XY_FINAL_M=0.35`). A waypoint value of the legacy 0.1 still reads as unset and maps to this value. Precision for nodes with actions comes from the action (e.g. dock), not from the node tolerance.
- **corridorWidth is per side:** `corridorWidth: 1.0` means a 2 m wide band (1 m each side of the edge).
- **Skip semantics (robot team reply):**
  - a) `skippable: true` without `corridorWidth` is treated as no skip. We always send both together.
  - b) A skip is reported as errorType `nodeSkipped`, errorLevel WARNING, errorReferences nodeId. It is not a block and must not fail or pause the mission.
  - c) A skip never happens on the start node or the last node, and never on two consecutive nodes.
  - d) `maxWaitS` counts from the first blocked verdict.
- **nodePolicy rollout:** `VDA5050_NODE_POLICY_MODE=off` in `.env.example` until the robot team confirms their nodePolicy release (otherwise the action is reported FAILED "Action handler not found"). Then switch to `factsheet` (or `on`). Phase 1: `maxWaitS` 10, `skippable` false. The code default is unchanged (`factsheet`).

## 2. DEFERRED: map / frame gating

Not done now; to be picked up after the joint test.

Current gaps:
- The server does not check `agvPosition.mapId` or `positionInitialized` before sending an order (`server.py` `_dispatch_hold_reason` ~1052; the values are only stored ~2430).
- `_route_in_robot_frame` (~2366) uses the DB session only, not what the robot reports.
- Node `nodePosition.mapId` comes from the waypoint `map_id`, not from `agvPosition.mapId`. The start node `mapId` is empty.
- In odometry mode the server sends `mapId ''` with no knowledge of the current session. The robot team asks: "how do you know which session is current?"

Proposal:
- Send an order only when the robot reports a saved map and `positionInitialized` is true.
- Use the reported map name as `mapId` on every node, including the start node.
- After the joint test the robot refuses mismatches with `validationError`.
- Joint test point 6 (frame) comes first.
