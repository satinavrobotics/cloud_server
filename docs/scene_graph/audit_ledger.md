# Scene graph audit ledger (2026-10-13)

**Purpose.** This ledger consolidates the findings from the 2026-10-13 scene graph work on the scratchpad ledgers (`ledger/store_io.md`, `ledger/chain_audit.md`, `ledger/sim_slow.md`, `ledger/construct.md`, `ledger/stationarity.md`, `ledger/morse.md`) and the end-to-end rehearsal report (`rehearsal/REPORT.md`). It records, for each finding, its evidence, its derivation, the change made, how it was verified and its decision. It copies or condenses the sources and does not add facts. Where two sources disagree, both are listed. Owner values are the sources' own labels (see the note under the table).

**Owner note (normalised: CIMBI = the engine/store side, LACI = ingest/worker/planner/API).** The first draft's "mine" is read as CIMBI.

**Owner note (original).** The sources do not define "mine". `chain_audit.md` marks its own fixes as "(mine)" and attributes other fixes to LACI. `REPORT.md` attributes engine and store items to CIMBI ("my engine" in that report). Rows from `store_io`, `sim_slow`, `construct`, `stationarity` and `morse` are the ledger author's own work, so they are marked "mine". Rows from `REPORT.md` keep its CIMBI or LACI labels.

**Decision key.** `fixed` = a source records a change and its verification. `not reproducible` = the sources record that the reported symptom did not occur. `refuted` = a later investigation refuted or overstated the claim. `open` = the source marks it open, pending, or not done. Where a source's status does not match these four words, the cell says so.
